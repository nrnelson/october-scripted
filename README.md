## WHAT THIS IS

[`october.py`](october.py) IS A **SCRIPT** THAT WRITES A **SCRIPT**: A REAL, PROPERLY FORMATTED SCREENPLAY CALLED **OCTOBER** ABOUT THE WORLD SERIES OF ANY YEAR IN THE FOX ERA (2000 AND LATER).

IT OPENS IN 2006, WITH THAT PROMO ON TV AND PATRUCK ON THE COUCH, EATING CHIPS, NOT ARGUING. THEN THE TYPEWRITER STARTS. UNLIKE THE ONE IN THE COMMERCIAL, **THIS ONE NEVER GETS A LINE CROSSED OUT.**

### FOR A WORLD SERIES THAT'S ALREADY HAPPENED (2000–2025)

THE SCRIPT TYPES THE RESULT BEFORE ANYONE THROWS A PITCH:

- **WHO BEAT WHO, AND IN HOW MANY GAMES**, DOWN TO THE DATE AND WEEKDAY OF THE CLINCHING GAME. ALL 26 SERIES WERE CHECKED AGAINST WIKIPEDIA AND BASEBALL-REFERENCE.
- **THE FOX BROADCAST BOOTH** CALLING THE LAST OUT, WITH THE COLOR ANALYST SIZING UP THE SERIES (A SWEEP IS "NOT A SCRIPT, THAT'S A PAMPHLET").
- **THE STORIES:** THE 2001 SERIES PLAYED INTO NOVEMBER FOR THE FIRST TIME, THE 2002 RALLY MONKEY, THE RED SOX ENDING 86 YEARS IN 2004, THE 2008 RAIN-SUSPENDED GAME 5, THE CUBS ENDING 108 YEARS IN 2016 AFTER A 17-MINUTE RAIN DELAY, THE 2019 NATIONALS WHERE THE ROAD TEAM WON ALL SEVEN, THE 2020 NEUTRAL-SITE SERIES, AND THE 18-INNING GAME 3 IN 2025.
- **THE MOON:** IT COMPUTES THE MOON PHASE FOR EVERY CLINCHING NIGHT WITH JEAN MEEUS'S LUNAR ALGORITHM. OUT OF ALL 26, IT FINDS A FULL MOON OVER EXACTLY ONE: **OCTOBER 27, 2004**, THE NIGHT THE RED SOX WON DURING A TOTAL LUNAR ECLIPSE. NOBODY TOLD THE MATH THAT. IT JUST KNEW.

## HOW TO RUN IT

YOU NEED PYTHON 3, AND NOTHING ELSE TO INSTALL. THE COMMANDS ARE LOWERCASE BECAUSE YOUR SHELL DOESN'T SHOUT BACK.

```bash
python3 october.py --year 2004              # THE CURSE, THE SWEEP, THE ECLIPSE
python3 october.py --year 2016 --play       # CUBS GAME 7, PERFORMED TYPEWRITER STYLE
python3 october.py                          # THIS YEAR: ALL 2,520 ENDINGS
python3 october.py --year 2019 -o october.fountain   # SAVE IT AS A SCREENPLAY FILE
```

## THE OUTPUT FORMAT

THE OUTPUT IS IN [FOUNTAIN](https://fountain.io), THE PLAIN-TEXT SCREENPLAY FORMAT. SCREENWRITING APPS LIKE HIGHLAND, FADE IN, BEAT AND SLUGLINE OPEN IT AS A PROPERLY FORMATTED SCREENPLAY. [`october-2004.fountain`](october-2004.fountain) IS A SAMPLE.
